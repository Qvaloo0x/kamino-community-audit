# Kamino Finance — Community Signals Audit

Independent exploratory research. July 2026.

## What this is
A corrected cross-platform metrics workbook for Kamino Finance.  
The first version claimed a causal link between community confusion and capital outflow. A source audit rejected that claim. This workbook documents what survived, what broke, and what I would measure next.

## What's in the file
- `kamino_audit_workbook.xlsx` — The full corrected workbook:
  - Sample metadata (30 X posts, Telegram 10 dates, Discord #general 15 dates)
  - Aggregated social metrics
  - QA framework and rejected claims log
  - Notes on data limitations

## Data sources
Publicly available material: X, Telegram, Discord, DeFiLlama, Token Terminal.  
Captured retrospectively on July 30, 2026. Not a continuous time series.

## Limitations
- X metrics captured once; older posts had longer accumulation windows
- On-chain series partially reconstructed from chart images
- Social and on-chain data have different precision levels
- No causal claims are supported by this sample
